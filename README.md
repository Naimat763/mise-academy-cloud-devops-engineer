# Day 1 — Networking Basics for Cloud

Today, I learned the fundamental networking concepts that are important for understanding cloud infrastructure and server communication.

### What is a Network?

A network connects computers and devices so they can communicate and share data and resources.

### What is a Router?

A router connects different networks and forwards data to the correct destination.

### What is the Internet?

The Internet is a global network of connected networks that allows devices and systems to communicate worldwide.

### Why Networking Matters in Cloud?

Cloud servers, applications, databases, and users depend on networking for communication, connectivity, and secure access.

### What is an IP Address?

An IP address is a numerical address used to identify a device or network interface on a network.

### What is DNS?

DNS (Domain Name System) translates domain names into IP addresses so systems can find the correct server or service.

### HTTP vs. HTTPS

HTTP is used for web communication, while HTTPS uses TLS to provide protected communication between clients and servers.

### What are Ports?

Ports are logical communication endpoints used by network services and applications. For example, SSH commonly uses port **22**.

### What is SSH?

SSH (Secure Shell) is a secure protocol used to remotely access and manage systems over a network.

### Public vs. Private IP Addresses

Public IP addresses can be reachable over the Internet, while private IP addresses are used inside private networks.
