# Day 1 - Cloud DevOps Fundamentals

## Institute

Mise Academy

## Topics Covered

### Computers, Servers & Operating Systems

Fundamentals of computers, servers, and operating systems and how they work together in an IT environment.

### What is a Computer System?

Understanding the relationship between hardware, software, data, and the operating system.

### Linux vs. Windows

Basic differences between Linux and Windows and their common use cases.

### What is a Server?

Understanding how servers provide services and resources to clients over a network.

### Server vs. Client

Understanding the client-server model and how requests and responses work.

### What is a CLI?

Understanding the Command Line Interface and its importance in Linux and server administration.

## Learning Outcome

Built a foundational understanding of computer systems, operating systems, servers, client-server architecture, and command-line interfaces as the starting point for Cloud DevOps learning.
